# Global development principles
- Follow KISS: prefer the simplest correct solution.
- Prioritize Clean Code: readability, clear naming, focused responsibilities, explicit behavior, and maintainability.
- Follow the Zen of Python where applicable: explicit > implicit, simple > complex, readability counts, practicality beats purity.
- Avoid premature abstraction, generalization, optimization, and overengineering.
- Do not add patterns, layers, dependencies, or indirection without a concrete need.
- Preserve project conventions and compatibility unless explicitly asked otherwise.
- Before finishing, remove unnecessary complexity and run relevant tests/checks when available.
